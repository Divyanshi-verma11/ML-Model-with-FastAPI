🚀 **Project Completed: Insurance Premium Category Prediction using Machine Learning**

I’m excited to share my Machine Learning project, where I built an interactive application to predict insurance premium categories based on user-related features.

💡 **Project Overview:**
The application takes user inputs such as age, weight, height, annual income, smoking status, city, and occupation to predict an insurance premium category using a trained Machine Learning model.

🛠️ **Technologies Used:**
- **Python** – Core programming language
- **Machine Learning** – Model-based prediction
- **FastAPI** – Building REST APIs for prediction
- **Pydantic** – Input validation and data preprocessing
- **Pandas** – Structuring and preparing input data
- **Streamlit** – Developing an interactive user interface
- **Pickle** – Loading the trained ML model

✨ **Key Features:**
✅ Interactive user interface for entering customer details  
✅ Automatic BMI calculation  
✅ Age group and lifestyle risk categorization  
✅ City-tier classification  
✅ Input validation using Pydantic  
✅ REST API integration using FastAPI  
✅ Real-time prediction through the Streamlit interface  

🎯 **What I Learned:**
This project helped me understand how to integrate a trained Machine Learning model with a backend API and an interactive frontend, along with handling input validation and data transformation in an end-to-end ML application.
